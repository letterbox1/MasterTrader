## Brand & Style

The design system embodies the high-velocity, rigorous domain of autonomous algorithmic trading and quantitative intelligence. It is crafted for algorithmic engineers, quantitative portfolio managers, and high-frequency digital asset traders who demand low-latency visual feedback, microsecond clarity, and high-density situational awareness.

The emotional baseline of the interface is calculated, unflinching, and sovereign. Rather than presenting gamified retail-broker tropes, the interface establishes a specialized cockpit environment where algorithmic models execute autonomously alongside human supervision.

The design movement combines **Deep Minimalist Terminal Architecture** with **Precision Quant Glassmorphism**:
- Ultra-dark foundational canvases allow signal mints, cobalt execution vectors, and telemetry nodes to stand out with immediate optical hierarchy.
- Micro-glass cards feature razor-thin 1px borders, subtle dark surface step-ups, and restrained neon luminescence reserved strictly for live states, active fills, and algorithmic convergence points.
- High data density is maintained through tabular figures, monospaced numeric alignments, and compact geometric envelopes.

## Colors

The palette directly matches the brand specifications, anchored in deep void tones to maximize contrast for live telemetry streams:

- **Ink (`#07090D`)**: The primary root background canvas. Absolute depth with zero light contamination.
- **Graphite (`#11151C`)**: The baseline container surface. Used for modular terminal tiles, sidebar docking docks, and inactive controls. Elevated surfaces use subtle step-ups to `#161B24` and `#1D232F`.
- **Signal Mint (`#2BE4A7` / `#0E8F69`)**: The primary action, positive delta, active agent status, and successful execution tone. `#2BE4A7` operates on dark terminal viewports, while `#0E8F69` is preserved for light-mode utility states or high-glare viewports.
- **Cobalt (`#3A7BFF` / `#2A5FE0`)**: The secondary systemic vector. Represents algorithmic routing, quantitative models, active order layers, and system interconnects.
- **Paper (`#EEF2F6`)**: The primary typographic and high-contrast foreground color, fading down through muted variants (`#8B95A5`, `#4F5969`) for metadata and micro-labels.
- **Flare Alert Coral (`#FF6B4A`)**: The tertiary emergency and negative delta accent. Strictly reserved for liquidation risk, margin thresholds, drawdown limits, stop-loss triggers, and operational errors. Never used decoratively.

## Typography

The typographic hierarchy enforces a dual-engine architecture:

1. **Space Grotesk (Human Layer)**: Used for layout headers, panel navigation, high-level structural metrics, modal titles, and brand wordmarks. Its technical geometry offers an authentic engineering character without degrading structural legibility.
2. **JetBrains Mono (Telemetry & Machine Layer)**: Exclusively governs financial values, book ladders, terminal execution streams, crypto ticker pairs (`BTCUSDT`), fill latencies, JSON runtime payloads, and precision timestamps. 

All numbers are rendered using tabular figures to prevent horizontal jitter during sub-second websocket streaming updates. Micro-labels, parameter keys, and state markers employ uppercase styling with increased letter spacing (`0.06em` to `0.08em`) to guarantee quick recognition in dense operational dashboards.

## Layout & Spacing

The terminal is structured on a fluid, modular tile grid system engineered for multi-monitor setups and dense analytical workflows:

- **Desktop (1440px+)**: Multi-panel modular workspace composed of 24 fractional columns or flexible CSS subgrids. Gutters are pinned at `1rem` to conserve screen space for depth charts, multi-asset matrices, and live order logs. Default outer margins sit at `1.5rem`.
- **Tablet / Laptop (768px - 1439px)**: Reflows into collapsible workspace panels. Lateral docks (such as order books and algorithm parameter trees) transform into slide-over sheets or secondary tabbed panes with `0.75rem` gutters.
- **Mobile (<768px)**: Strict vertical single-column stack with unified bottom floating command bars. Secondary charts collapse into swipeable cards.

Spacing is compressed to prioritize immediate situational awareness. Vertical element paddings within order books, execution ladders, and parameter forms run on tight 4px and 8px baselines (`space-xs` and `space-sm`), reserving larger padding (`space-lg` to `space-xl`) strictly for modal views and standalone onboarding workflows.

## Elevation & Depth

Visual depth is achieved through layered tonal dark surfaces and glassmorphic micro-borders, avoiding heavy blur shadows that clutter technical screens:

- **Ground Level (Canvas)**: Solid Ink (`#07090D`). The foundational host for the entire workspace.
- **Level 1 (Dock & Tiles)**: Graphite (`#11151C`) with an ultra-fine border: `1px solid rgba(238, 242, 246, 0.07)`. Semi-translucent panels incorporate `backdrop-filter: blur(12px)`.
- **Level 2 (Active Sub-Panels / Inputs)**: Deep Graphite tint (`#161B24`) with `1px solid rgba(238, 242, 246, 0.12)`.
- **Level 3 (Modals / Overlays / Flyouts)**: Elevated Graphite (`#1D232F`) with `1px solid rgba(58, 123, 255, 0.35)` and a directional edge shadow: `0 8px 32px -4px rgba(0, 0, 0, 0.75)`.

### Candlestick Node Illumination
Selected execution pathways, active bots, and break-even points employ subtle directional glow halos. Glowing nodes use a radial emission: `box-shadow: 0 0 12px rgba(43, 228, 167, 0.45)`. Coral warnings emit an alert pulse: `box-shadow: 0 0 14px rgba(255, 107, 74, 0.5)`. Ambient drop shadows are neutral dark, never muddying the background data layers.

## Shapes

The geometric framework balances technical rigor with modern ergonomics:

- Base corner radii default to **0.5rem (8px)**, providing crisp definition across terminal tiles, order modules, and table container boundaries.
- Nested child nodes, action buttons, price pill badges, and input selectors scale down to **0.25rem (4px)** to maintain mathematical visual concentricity inside parent tiles.
- Large modal dialogs and alert surfaces scale up to **1rem (16px)**.
- Telemetry indicators, autonomous status dots, and live wick nodes remain perfect circles (`rounded-full`), mirroring the candlestick data-point icon anatomy established in the brand identity.

## Components

### Buttons & Interactive Triggers
- **Primary Signal Action (Buy / Start Agent / Confirm)**: Solid Signal Mint (`#2BE4A7`) fill with Ink (`#07090D`) typography (`Space Grotesk` 600). Hover produces a subtle brighten state and an 8px mint bloom.
- **Secondary System Action (Order Route / Backtest)**: Solid Cobalt (`#3A7BFF`) fill with Paper (`#EEF2F6`) typography.
- **Emergency / Liquidation Action (Cancel All / Stop Loss)**: Translucent Coral fill (`rgba(255, 107, 74, 0.15)`) bordered with `1px solid #FF6B4A` and Flare text. On hover, shifts to solid Flare fill with Ink text.
- **Ghost / Tool Action**: Borderless with Graphite hover states, retaining crisp 12px mono icons.

### Quant Cards & Terminal Tiles
Constructed with Graphite backgrounds, `1px solid rgba(238, 242, 246, 0.08)` borders, and 8px corners. Tile headers feature a dedicated 32px height bar with 10px uppercase `Space Grotesk` titles, an active data stream indicator, and micro window controls (maximize, minimize, close).

### Chips, Pills & Status Nodes
- Dynamic status chips use `JetBrains Mono` at 11px.
- **Running / Signal In-Bounds**: `rgba(43, 228, 167, 0.12)` background, Signal Mint text, with a pulsing 6px mint node.
- **Idle / Synced**: `rgba(58, 123, 255, 0.12)` background, Cobalt text.
- **Warning / Breach**: `rgba(255, 107, 74, 0.15)` background, Flare Coral text.

### Telemetry Logs & Order Book Lists
- Order book rows are locked to 20px heights. Real-time depth bars render horizontally behind prices using low-opacity mint (`rgba(43, 228, 167, 0.12)`) for bids and low-opacity coral (`rgba(255, 107, 74, 0.12)`) for asks.
- Quant log rows alternate between `#11151C` and transparent lines with micro-level timestamp indexing in muted gray.

### Inputs, Sliders & Precision Controls
- Number and parameter inputs use inset Graphite fields with `1px solid rgba(238, 242, 246, 0.15)`. Focused fields illuminate their perimeter in Cobalt (`#3A7BFF`).
- Stepper handles, leverage sliders, and toggle switches use high-contrast Paper grips with immediate Signal Mint fill tracks.

### Specialized Candlestick Telemetry Accents
- Candlestick wicks use clean 1px hairline rods with 4px wide bodies.
- Key algorithmic inflection points (such as strategy trigger points and AI decision nodes) render an accented circular node directly centered across the candle body, echoing the brand mark.

# P7-T042 · Recurring 12-month review: yearly review task and keep/retire report

## Goal / expected outcome

The 12-month review runs as a **recurring calendar review** outside the phases ([roadmap README §10](../../../docs/roadmap/README.md#10-standing-operations-recurring-outside-the-phases)): from each sleeve's first live funding, the system opens a yearly `REVIEW_12M` task (Telegram + D13) with an evidence report that evaluates the sleeve against the keep criteria and proposes keep/retire. This item builds that schedule and report; the reviews themselves are standing operations, not phase work.

## Context & references

- Roadmap: [R7.05 · ToDo T7.10](../../../docs/roadmap/phase-7-prove-and-go-live.md) (T7.82 is deferred to the recurring review, [README §10](../../../docs/roadmap/README.md#10-standing-operations-recurring-outside-the-phases))
- Spec: [14 §7](../../../docs/14-strategy-evidence-and-validation.md#7-phase-capital-steps--kill-criteria-refines-04-phase-7) (12-month review: keep only sleeves with positive live net P&L, live Sharpe > 0.5 over 12 months, and beating the benchmark) · [14 §1](../../../docs/14-strategy-evidence-and-validation.md#1-viability-verdict-set-expectations-before-building) (benchmark rule; capital of failing strategies to hold-and-earn)

## Requirements

- Per sleeve over its live window (target 12 months; report shows actual length): net P&L after all costs (journal), annualised Sharpe of daily returns, benchmark return over the same dates, kill/decay events, capital-step history.
- Proposal: `keep` only if all three criteria pass; else `retire` (capital to hold-and-earn task).
- Schedule: a yearly `REVIEW_12M` task per sleeve from its `live_started_at`, plus a monthly interim report (marked 'interim', no proposal); cancelled with a reason if the sleeve retires earlier.
- Report stored WORM (`strategy.review_12m`) with its artefact, attached to the task and linked from D03 and D14; generated by a scheduled flow (no new `mt_api` command; 02 §7 stays the catalogue).

- Sleeve live < 12 months at programme review: interim only.
- Benchmark data gap: criterion `unknown` → proposal `retire` (fail closed).

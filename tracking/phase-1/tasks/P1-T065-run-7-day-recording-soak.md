# P1-T065 · Run the 7-day continuous recording soak

## Goal / expected outcome

The full P1 stack records the agreed universe for 7 consecutive days without manual intervention, producing a gap report per instrument and disk growth measured against the storage budget.

## Context & references

- Roadmap: requirements [R1.N3](../../../docs/roadmap/phase-1-data-and-monitoring.md#3-requirements), [R1.02](../../../docs/roadmap/phase-1-data-and-monitoring.md#3-requirements), [R1.10](../../../docs/roadmap/phase-1-data-and-monitoring.md#3-requirements) · ToDo [T1.80](../../../docs/roadmap/phase-1-data-and-monitoring.md#4-todo-sets)
- Roadmap T1.80 · budget R1.N3 ([03 M1](../../../docs/03-build-spec.md#m1-market--macro-data--mt_datamarket)) · gap report from P1-T032 · storage metrics P1-T052
- Depends on (this phase): P1-T001, P1-T052, P1-T053, P1-T054, P1-T057, P1-T061

## Requirements

- Start only after the universe (P1-T001) is merged and all connectors run; freeze config for the 7 days (no deploys except emergency fixes, logged)
- Daily check (2 min): D07 KPI strip screenshot and any incidents noted in the progress log
- End report: per instrument gaps (count, total seconds, longest, cause), recorder loss (expected 0), restarts, incidents by type, alert counts per channel, bytes/day per venue/type and projected yearly growth vs ~0.3–1 TB, CPU/RAM peaks
- Report under `reports/run/P1-T065/`

## Verification

### Tests

- End report generated by `mt-monitor soak-report --from --to` (gap report + storage + incidents)

### Scenarios

- Given a venue outage during the soak, when it recovers, then the report shows the gap with its cause and the backfill that closed it (where history exists)

### Stress / failure injection

- This is the endurance test: 7 × 24 h continuous operation

## Acceptance criteria

- [ ] 7 days completed without manual restarts (automatic reconnects are fine)
- [ ] Projected yearly storage inside ~0.3–1 TB for the crypto universe, or the overrun and fix (e.g. fewer L2 symbols) recorded
- [ ] Every gap explained in the report

## Exceptions & edge cases

- If an emergency fix is deployed, the soak continues but the report flags it; a restart of the 7-day clock is your call (P1-T066)
